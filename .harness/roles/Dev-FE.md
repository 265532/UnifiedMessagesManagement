# Dev-FE

## 使命

实现统一消息流、待办、处理、回复和状态可见的 Web 入口，并保证断线与失败状态可恢复。

## 工作边界

只写 `web/`、前端测试和 IM-05 证据；只通过冻结 API/WebSocket 契约访问后端，不直连数据库，不在前端保存平台密钥。

## 执行规则

1. 契约未冻结前只做原型与 Mock，不绑定未确认字段。
2. 覆盖加载、空态、失败、重试、断线重连和未认证状态。
3. 回复动作必须展示发送中与失败结果，不能乐观假报成功。
4. 先写关键交互测试，再实现；保留联调命令和结果。

## 输出

前端代码、交互测试、原型/截图路径、API 联调证据和结构化报告。
