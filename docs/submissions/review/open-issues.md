# 初赛资料未决事项与证据边界

> 最后复核：2026-11-20。本表只记录未决项和处理边界，不把生成文件等同于官方验收通过。

| 编号 | 事项 | 当前口径 | 影响 / 下一步 |
|---|---|---|---|
| OI-01 | 钉钉平台侧证据 | 据用户陈述，已有真实收发、回调和回执；截图、日志、消息 ID、复跑步骤、时间和环境尚未归档 | `05_初步验证` 保留证据位，现阶段不得写成已复核通过 |
| OI-02 | 钉钉产品代码 | 仓库内未发现统一消息产品源码；平台侧接通不等于统一入口闭环已实现 | 需提供代码位置或补齐最小闭环 |
| OI-03 | 飞书接通 | 尚未接通 | 双平台 Must 闭环暂不能写成验证通过 |
| OI-04 | 统一 Web 产品页面 | 尚无真实产品页面；静态原型截图只用于 `02_原型设计` | 不能用原型替代真实验证或源代码初版 |
| OI-05 | 可运行初版 | 尚无产品代码、迁移、启动命令实际结果和干净 checkout 记录 | `06_其他/代码仓库与运行说明.md` 只记录设计运行方式与待验证状态 |
| OI-06 | AI 专项对话链接 | 按用户要求生成统一占位模板，尚无真实链接 | 最终提交前须由用户逐文档替换为真实、可公开且无隐私的链接 |
| OI-07 | PDF 成品 | 当前本地 Office 路由不支持生成 PDF；已交付两份可编辑 DOCX | 需用户在 Word/WPS 中另存 PDF，并对精简设计实测不超过 10 页；`page-budget` 因无实测页数如实未通过 |
| OI-08 | 官方提交入口与压缩规则 | 用户要求忽略截止时间，其他入口、命名与大小限制未提供 | 本次仅整理 `release/` 包，不写入口细节 |
| OI-09 | 演示视频 | 用户明确暂无且不需要补录 | 不创建视频占位文件 |
| OI-10 | Word 字号冲突 | 提交计划要求正文五号；当前生成通道最低 12pt；用户已确认本次采用宋体小四 12pt | 已在元数据与成品中记录，不视为未决冲突 |
| OI-11 | 页数实测 | 无 PDF 成品，无法填写实测页数 | 不得为了通过 `page-budget` 虚构页数 |
